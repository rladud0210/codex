Pattern

패턴 핵심 정리

  1. 1. 최소 견본 만들기 반복되는 가장 작은 모양을 먼저 정리하고, 그 조각을 패턴의 기본 단위로 잡습니다.
  2. 2. 스와치 패널에 등록 완성된 최소 단위를 Swatches 패널에 넣어두면 이후 면 채우기에 바로 사용할 수 있습니다.
  3. 3. 패턴 수정은 변형 기능으로 접근 패턴 자체를 다시 만들기보다 Transform Patterns 옵션으로 패턴의 방향과 배치를 조정합니다.
  4. 4. 환경설정도 함께 확인 Ctrl + K로 환경설정에 들어가 Transform Pattern Tiles 관련 옵션을 체크해 둡니다.
Appearance

Appearance 패널에서 기억할 것

  • 개체의 모든 속성을 보여준다 현재 오브젝트가 가진 채우기, 선, 효과를 한 번에 확인하는 패널입니다.
  • Fill과 Stroke를 여러 개 추가할 수 있다 단일 오브젝트라도 여러 겹의 색과 선을 쌓아 사용하는 방식이 가능합니다.
  • 수정은 개체를 다시 그리기보다 속성 조절로 비파괴적으로 조절할 수 있어서 실무 작업 속도가 훨씬 안정적입니다.
