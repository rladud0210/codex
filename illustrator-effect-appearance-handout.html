Illustrator Class Note

Effect와 Appearance는
모양을 만들고 관리하는 핵심 도구

Illustrator의 Effect는 개체에 시각 효과를 적용하는 기능이고, Appearance는 그 개체가 가진 속성과 효과를 한눈에 보여주고 수정하게 해주는 패널이다.

외워둘 포인트
  • Effect > Offset Path는 원본을 유지한 채 여백 느낌을 조절한다.
  • Object > Path > Offset Path는 경로를 복제해 새로운 개체를 만든다.
  • Appearance 패널에서는 적용된 효과를 다시 눌러 수정할 수 있다.

1. Illustrator Effect

효과 메뉴는 개체를 직접 다시 그리지 않고도 다양한 변형과 스타일을 빠르게 줄 때 사용한다.

effect basics
Distort & Transform

모양을 찌그러뜨리거나 반복 변형

  • Pucker & Bloat : 중심을 기준으로 안쪽으로 오므리거나 바깥으로 부풀린다.
  • Transform : 이동, 회전, 크기 변경, 복제를 한 번에 제어한다.
  • Zig Zag : 선이나 도형의 가장자리를 지그재그나 물결 모양으로 바꾼다.
같은 도형도 직접 수정하지 않고 효과만으로 다양한 시안 변형을 빠르게 만들 수 있다.
Stylize

입체감과 분위기 추가

  • Drop Shadow : 그림자를 넣어 떠 있는 느낌을 만든다.
  • Outer Glow : 바깥쪽 광택이나 퍼지는 빛 효과를 만든다.
  • 등등 : Feather, Scribble 같은 스타일 계열도 함께 자주 묶여 나온다.
Stylize 계열은 디자인을 화려하게 만들지만, 너무 많이 겹치면 지저분해질 수 있으니 강도 조절이 중요하다.

2. Path와 Offset Path

같은 이름처럼 보이지만, 어디에서 실행하느냐에 따라 결과가 다르다.

must know
Effect > Path

원본 유지형 Offset Path

  • Effect > Path > Offset Path
  • 개체 자체의 여백을 조절하는 느낌으로 사용한다.
  • 원본 경로는 그대로 두고, 효과처럼 덧씌워진 상태로 보인다.
  • 나중에 Appearance 패널에서 수치를 다시 바꿀 수 있다.
Object > Path

복제 생성형 Offset Path

  • Object > Path > Offset Path
  • 경로가 자동으로 하나 복제된다.
  • 효과가 아니라 실제 새 오브젝트가 만들어지는 개념이다.
  • 윤곽선 따기, 외곽 배경 만들기, 실제 도형 분리 작업에 유리하다.
언제 Effect로 쓰나?

수정 가능성을 남겨두고, 여백 수치를 계속 조절해야 할 때.

언제 Object로 쓰나?

실제 경로가 필요하거나, 복제된 도형을 따로 선택해서 편집해야 할 때.

3. Photoshop Effect 비교

포토샵에서는 같은 “effect”라도 주로 필터 중심으로 접근한다.

cross check
Filter Gallery

여러 필터를 미리보기하면서 질감, 왜곡, 회화 느낌 등을 빠르게 적용할 수 있다.

Blur

흐림 효과를 통해 배경 분리, 초점 표현, 부드러운 분위기를 만든다.

4. Appearance 패널

개체가 가지고 있는 모든 속성을 보여주고, 적용된 효과를 다시 수정하는 기능이다.

appearance

Appearance에서 볼 수 있는 것

  • Fill, Stroke 같은 기본 속성
  • 적용된 Effect 목록
  • Offset Path, Transform 같은 세부 효과
  • 효과 순서와 적용 여부

Appearance의 장점

  • 효과를 다시 눌러 수치 수정 가능
  • 원본 개체를 유지하면서 시각 효과만 바꾸기 쉬움
  • 복잡한 디자인도 구조를 파악하기 쉬움
  • 여러 속성을 한 패널에서 관리 가능
수업에서 자주 보는 Offset Path와 Transform은 Appearance 패널에서 다시 선택해 수정하는 습관을 들이면 작업 속도가 빨라진다.
