곡률 펜, 앵커포인트, 스트로크 핵심 복습

곡선을 깔끔하게 다루는 데 필요한 핵심만 모은 수강생용 복습 자료입니다. 포인트를 어디에 찍어야 하는지, 핸들을 어떻게 유지해야 하는지, 그리고 Object > Path 관련 기능을 언제 쓰는지 한 번에 정리했습니다.

도구 정리 펜툴 핵심 Stroke · Path 복습문제
복습문제 풀기
앵커포인트 위치 정확하게 핸들 흐름 끊지 않기 진행방향으로 핸들 뻗기 포인트 개수 최소화
오늘 복습 포인트

직선을 기준으로 포인트 위치를 먼저 생각하고, 곡률이 시작하는 지점과 끝나는 지점, 꼭대기를 정확히 잡는 연습이 중요합니다.

자주 틀리는 부분

곡선 중간에 괜히 포인트를 많이 찍거나, 진행방향 반대로 핸들을 꺾어서 형태가 지저분해지는 경우가 많습니다.

수업 메모

Ctrl 로 그리는 중 포인트를 수정하고, Offset Path 는 일정 여백을 만들 때 가장 많이 씁니다.

도구 빠른 정리

먼저 각 도구가 무슨 역할인지 짧고 정확하게 익히세요. 비슷해 보이지만 쓰는 타이밍이 다릅니다.

핵심 도구 4개
Tool 01

Curvature Tool 곡률 펜도구

핸들을 직접 길게 빼지 않아도 곡선을 쉽게 만드는 도구입니다. 부드러운 곡선 형태를 빠르게 잡을 때 유용합니다.

  • 초보자가 곡선 흐름을 익히기 좋습니다.
  • 포인트 위치가 어긋나면 전체 곡선도 같이 무너집니다.
Tool 02

Add Anchor Point 앵커포인트 추가

이미 만들어진 패스 위에 포인트를 더 넣는 기능입니다. 세부 굴곡을 더 세밀하게 조절할 때 사용합니다.

  • 필요한 곳에만 추가합니다.
  • 불필요한 추가는 패스를 지저분하게 만듭니다.
Tool 03

Delete Anchor Point 앵커포인트 삭제

필요 없는 포인트를 줄여 패스를 단순하게 정리합니다. 포인트 개수를 최소한으로 유지하는 데 꼭 필요합니다.

  • 형태가 유지되는지 확인하며 삭제합니다.
  • 복잡한 패스를 깔끔하게 다듬을 때 자주 씁니다.
Tool 04

Anchor Point Tool

직선 포인트와 곡선 포인트를 전환하고, 핸들을 자유롭게 편집하는 도구입니다.

  • 직 → 곡: 드래그해서 핸들 추가
  • 곡 → 직: 클릭해서 핸들 삭제
  • 핸들을 한쪽씩 따로 꺾어 자유롭게 조절 가능

Anchor Point Tool 기억법

핸들이 없으면 직선 포인트, 핸들이 있으면 곡선 포인트라고 먼저 생각하면 헷갈림이 줄어듭니다. 드래그는 곡선 만들기, 클릭은 직선으로 되돌리기입니다.

드래그 직선을 곡선으로 클릭 곡선을 직선으로

패스 정리 기준

포인트를 추가하는 것보다 먼저, 기존 포인트 위치를 옮기거나 핸들 각도를 조절해서 해결할 수 있는지 확인하세요.

펜툴 핵심 원칙

아래 네 가지는 실제 작업에서 가장 많이 강조되는 기준입니다. 그냥 외우지 말고, 그릴 때 바로 체크하는 습관을 들이세요.

중요도 ★★★
1. 앵커포인트 위치를 정확히 찍기
  • 곡선으로 보기 전에 먼저 직선이라고 생각하고 포인트 위치를 잡습니다.
  • 곡률이 시작하는 부분, 끝나는 부분, 꼭대기에 찍는 것이 기본입니다.
2. 곡선을 그리는 중 핸들 끊지 않기

중간에 핸들이 끊기면 흐름이 부자연스러워지고, 다시 맞추는 데 시간이 더 걸립니다. 가능하면 연결감을 유지하세요.

3. 핸들은 항상 진행방향으로 뻗기

다음으로 이어질 방향을 미리 생각하고 핸들을 빼야 곡선이 부드럽게 이어집니다.

4. 앵커포인트 개수는 최소한

점이 많다고 정교한 것이 아닙니다. 적은 포인트로 정확한 형태를 만드는 것이 좋은 패스입니다.

펜툴 사용 기본

  1. 직선 그리기: 클릭, 클릭
  2. 곡선 그리기: 클릭, 드래그
  3. 그리는 중 편집: Ctrl 누르고 포인트 또는 핸들 조절

수업용 체크 문장

“점은 적게, 위치는 정확하게, 핸들은 진행방향으로.” 이 한 문장으로 펜툴 기본을 반복해서 점검하면 좋습니다.

Stroke · Object > Path 기능 정리

펜툴로 그린 뒤에는 패스를 정리하거나 여백을 균일하게 조절하는 기능을 자주 사용합니다. 특히 Offset Path 는 반드시 익혀야 합니다.
