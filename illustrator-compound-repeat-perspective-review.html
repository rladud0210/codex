컴파운드 패스부터 원근감 격자까지 빠르게 복습하기

요청한 항목만 시험 직전용으로 압축했다. 단축키, 기능 개념, 바로 확인 가능한 문제 풀이를 한 페이지 안에 넣어서 수업 배포용으로 바로 쓸 수 있게 구성했다.

컴파운드 패스 Offset Path Make with Warp 반복 라이브페인트 원근감 격자
핵심 정리 암기 포인트 복습 문제
Ctrl + 8
Ctrl + B
Ctrl + C

핵심 정리

헷갈리는 기능명을 단어 하나씩 쪼개지 말고, "언제 쓰는지"와 "무슨 결과가 나오는지"로 묶어서 보는 쪽이 기억에 오래 남는다.

시험 직전 3분 복습

컴파운드 패스

  • 여러 오브젝트를 하나의 경로처럼 처리한다.
  • 겹친 도형 안쪽을 뚫어 문자, 로고, 구멍 난 형태를 만들 때 자주 쓴다.
  • 바로 떠올릴 단축키는 Ctrl + 8 이다.

제자리 복제 뒤로 붙이기

  • Ctrl + C 로 복사하고 Ctrl + B 로 뒤에 붙여넣는다.
  • 같은 위치에 복제본이 생기고 원본 뒤에 쌓인다.
  • 외곽 장식, 그림자 베이스, 뒷판 만들기에서 많이 쓴다.

Offset Path / Make with Warp

  • Offset Path: 경로에서 일정 간격 떨어진 새 경로를 만든다.
  • Make with Warp: 오브젝트나 글자를 아치, 물결 같은 형태로 왜곡한다.
  • 둘 다 "모양을 변형한다"는 공통점이 있지만, 방식은 전혀 다르다.

반복 / 라이브페인트 / 원근감 격자

  • 반복: 규칙적으로 자동 복제한다.
  • 라이브페인트: 선으로 나뉜 영역을 색칠하듯 채운다.
  • 원근감 격자: 원근 공간에 맞춰 오브젝트를 배치한다. 토글은 Ctrl + Shift + I.

암기 포인트

이 파트는 기능명과 결과를 짧게 연결하는 구간이다. 입으로 읽듯이 한 줄씩 외우면 빠르다.

Ctrl + 8 컴파운드 패스 만들기. 겹친 도형 안쪽이 뚫리는 형태를 떠올린다.
Ctrl + C / Ctrl + B 복사 후 뒤에 붙여넣기. 같은 자리에 복제되고 레이어 순서상 뒤로 들어간다.
Offset Path 원본에서 일정 간격 떨어진 새 경로 만들기. 외곽선 확장, 테두리, 여백 제작.
Make with Warp 아치, 볼록, 물결처럼 왜곡. 특히 텍스트 변형 문제에서 자주 보인다.
Ctrl + Shift + I 원근감 격자 켜기 / 끄기. 격자가 보였다 사라지는 토글 단축키다.
기능명 바로 기억할 핵심 주로 쓰는 상황
컴파운드 패스 여러 도형을 하나의 경로처럼 처리 구멍 뚫린 글자, 도형 결합 표현
반복 자동 규칙 복제 패턴, 좌우 대칭, 원형 배열
라이브페인트 영역 단위로 색칠 선 드로잉 채색, 구획별 색 넣기
원근감 격자 원근 공간에 맞춘 배치 건물, 도로, 입체 공간 구성

복습 문제

선택하고, 입력하고, 바로 채점할 수 있게 만들었다. 수업 중 확인용이나 개인 복습용으로 그대로 쓰면 된다.

1. 컴파운드 패스 단축키

컴파운드 패스를 만드는 단축키를 고르세요.

2. 제자리 복제 뒤로 붙이기

복사 후 뒤에 붙여넣는 조합을 고르세요.

3. 빈칸 채우기

Offset Path 는 기존 경로에서 일정 _____ 만큼 떨어진 새 경로를 만든다.

4. 기능 연결

글자나 오브젝트를 아치 형태처럼 왜곡할 때 가장 알맞은 기능을 고르세요.

5. 체크 문제

다음 중 설명이 맞는 것을 모두 고르세요.

6. 원근감 격자 단축키

원근감 격자를 켜고 끄는 단축키를 입력하세요.
