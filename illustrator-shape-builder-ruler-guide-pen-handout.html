쉐입빌더 도형 구성 도구

도형을 만든 뒤 필요한 부분만 더하고, 빼고, 나누는 데 가장 직관적인 도구입니다.

핵심 조작

1. 더하기

  • 겹친 도형 위를 드래그합니다.
  • 이어진 영역이 하나의 면처럼 합쳐집니다.
  • 여러 영역을 한 번에 묶고 싶을 때 빠릅니다.

2. 빼기

  • Alt 를 누른 채 클릭하면 해당 영역만 제거됩니다.
  • Alt 를 누른 채 드래그하면 지나간 여러 영역을 한 번에 제거할 수 있습니다.
  • 삐져나간 조각이나 불필요한 면 정리에 유리합니다.

3. 나누기

  • 분리할 영역을 클릭합니다.
  • 영역 하나하나를 독립된 조각처럼 나눌 때 사용합니다.
  • 나중에 개별 색상 적용이나 이동을 할 때 편합니다.

쉐입빌더를 쓰기 전 체크

  • 어떤 영역을 합칠지 먼저 눈으로 구분합니다.
  • 어떤 부분을 삭제할지 미리 정합니다.
  • 한 번에 여러 기능을 섞어 써야 하는지 확인합니다.
  • 도형 외곽에 남는 찌꺼기 정리가 필요한지 봅니다.

패스파인더 vs 쉐입빌더

둘 다 도형을 합치고 자르는 도구이지만, 작업 방식이 다릅니다. 상황에 맞게 선택해야 속도가 납니다.

선택 기준
바깥쪽 삐져나간 개체 정리 쉐입빌더가 적합합니다. 필요한 부분만 골라 빼기 쉽기 때문입니다.
여러 개체에 여러 기능 사용 쉐입빌더가 적합합니다. 더하기, 빼기, 나누기를 한 흐름에서 섞어 쓸 수 있습니다.
여러 개체에 한 가지 기능만 사용 패스파인더가 적합합니다. 한 번의 명령으로 빠르게 처리할 수 있습니다.
작업 감각 패스파인더는 명령 중심, 쉐입빌더는 영역을 직접 만지며 편집하는 방식입니다.

눈금자와 가이드 단축키

배치와 정렬을 정확하게 만들려면 화면 기준선을 빨리 켜고 끄는 습관이 중요합니다.

단축키 복습
Ctrl + R
눈금자 켜기 / 끄기

아트보드 주변 기준 단위를 빠르게 확인할 때 사용합니다. 정확한 위치 감각을 잡는 기본 단축키입니다.

Ctrl + 5
가이드 만들기

선택한 선이나 도형을 가이드로 바꿉니다. 레이아웃 기준선이나 정렬 기준을 직접 만들 때 사용합니다.

눈금자는 위치를 읽는 기준이고, 가이드는 작업 화면에 직접 남겨두는 기준선입니다. 둘을 구분해서 기억하면 단축키가 헷갈리지 않습니다.

펜툴 핵심 규칙 ★★★

펜툴은 손재주보다 판단 순서가 중요합니다. 포인트를 어디에 찍을지 먼저 정하고, 핸들을 진행 방향으로 뻗는 습관을 가져야 합니다.

가장 중요

1. 앵커포인트 위치를 정확하게 찍기

  • 처음부터 곡선으로만 보지 말고 직선 구조를 먼저 생각합니다.
  • 곡률이 시작하는 부분, 끝나는 부분, 꼭대기를 찾습니다.
  • 포인트 위치가 맞아야 나중에 핸들 조절도 쉬워집니다.

2. 곡선을 그리는 중에는 핸들을 함부로 끊지 않기

  • 매 포인트마다 핸들을 끊으면 곡선 흐름이 끊깁니다.
  • 자연스러운 곡선은 연결된 방향성이 유지되어야 합니다.
  • 정말 방향 전환이 필요한 지점에서만 분리합니다.

3. 핸들은 항상 진행 방향으로 뻗기

  • 다음에 이어질 곡선 방향을 예상하며 핸들을 보냅니다.
  • 반대 방향으로 무리하게 잡으면 곡선이 울거나 꺾입니다.
  • 진행 방향 의식이 곡선 품질을 좌우합니다.

4. 앵커포인트 개수는 최소한

  • 포인트가 많아질수록 수정은 어려워집니다.
  • 적은 포인트로 큰 흐름을 잡는 것이 더 안정적입니다.
  • 필요한 곳만 남기는 습관이 패스 편집을 편하게 만듭니다.
포인트 곡선의 시작, 끝, 꼭대기를 찾기
생각 순서 곡선보다 직선 구조를 먼저 보기
핸들 진행 방향으로 자연스럽게 뻗기
편집 포인트 개수는 최소한으로 유지하기
패스를 편집할 때 가장 먼저 체감되는 차이는 포인트 수입니다. 처음부터 포인트를 많이 찍어두면 수정이 복잡해지고, 최소 포인트로 구조를 잡아두면 곡선 조절과 형태 수정이 훨씬 쉬워집니다.
