Illustrator Review Sheet

마스크, 투명도, 이미지 관리 복습자료

수업에서 바로 다시 볼 수 있게 핵심 개념만 남긴 정리본입니다. 클리핑 마스크, 컴파운드 패스, 불투명 마스크, 블렌딩 모드, 이미지 관리 순서로 복습하면 됩니다.

오늘의 핵심

클리핑 마스크는 “액자 안에 그림 넣기”, 불투명 마스크는 “비파괴적으로 지우기”입니다.

먼저 기억할 것

레이어 순서와 패스 상태를 먼저 확인해야 마스크가 제대로 작동합니다.

Clipping 클리핑 마스크 만들기 Ctrl + 7
Compound 컴파운드 패스 만들기 Ctrl + 8
Arrange 맨 앞으로 보내기 Ctrl + Shift + ]
Clipping Mask

클리핑 마스크

`액자` 안에 `그림`을 집어넣는 기능입니다. 위에 있는 패스가 보이는 영역을 결정합니다.

  1. 1. 이미지 위치 및 크기 수정
    더블클릭해서 수정 모드로 들어가거나 `Direct Selection Tool`로 선택해서 이동, 확대, 축소합니다.
  2. 2. 레이어 순서 확인
    액자가 될 개체가 반드시 위에 있어야 합니다. 적용 전 `Ctrl + Shift + ]`로 맨 앞으로 올리면 안전합니다.
  3. 3. 패스 상태 확인
    `Fill`, `Stroke`, 투명 여부는 상관없습니다. 핵심은 액자가 될 개체가 `패스`여야 한다는 점입니다.
  4. 4. 둘 다 선택 후 적용
    액자와 그림을 함께 선택하고 우클릭해서 `Make Clipping Mask`를 실행합니다.
  5. 5. 액자는 한 번에 하나만
    한 개의 클리핑 마스크에는 액자 개체를 하나만 직접 사용할 수 있습니다.
Compound Path

컴파운드 패스

거리가 떨어져 있는 개체도 `비파괴적으로` 하나처럼 합칠 수 있는 기능입니다. 여러 개의 액자를 한 번에 써야 할 때 먼저 처리합니다.

  • 적용 단축키
    `Ctrl + 8`
  • 왜 필요한가
    클리핑 마스크에서 여러 개의 구멍이나 여러 개의 액자 모양을 하나의 마스크처럼 쓰기 위해 필요합니다.
  • 중요 주의사항
    그룹으로 묶여 있는 개체를 우클릭했을 때는 `Make Compound Path`가 바로 안 뜰 수 있습니다.
  • 작업 팁
    여러 개체를 그룹으로만 묶는 것과 컴파운드 패스로 합치는 것은 다릅니다. 마스크용이면 컴파운드 패스를 먼저 의심합니다.

복붙 보조 단축키

`Ctrl + C` 후 `Ctrl + F`를 사용하면 같은 위치에 붙여넣을 수 있어 마스크용 도형을 복제할 때 편합니다.

실수 포인트

그룹 상태로만 두고 클리핑 마스크를 만들면 원하는 대로 뚫린 모양이 나오지 않을 수 있습니다.

Transparency

불투명 마스크

개체를 `비파괴적으로 지울 수 있는 기능`입니다. 포토샵의 레이어 마스크와 같은 개념으로 이해하면 됩니다.

  • 명도 인식
    검은색은 지워지고, 회색은 반투명해지고, 흰색은 변화가 없습니다.
  • 활용 방식
    가장자리 페이드아웃, 부드러운 합성, 자연스러운 삭제 표현에 많이 씁니다.
  • 그라디언트 활용
    그라디언트를 넣으면 한 번에 부드러운 투명도 변화를 만들 수 있습니다.
  • 관련 도구
    `G` : Gradient Tool
Quick Compare

마스크 구분

둘 다 비파괴 방식이지만, 작동 원리는 완전히 다릅니다.

  • 클리핑 마스크
    패스 모양으로 보이는 영역을 잘라냅니다. 딱 떨어지는 액자형 작업에 적합합니다.
  • 불투명 마스크
    검정, 회색, 흰색의 명도로 투명도를 조절합니다. 부드러운 사라짐이나 페이드 표현에 적합합니다.
  • 한 줄 기준
    형태로 자르면 클리핑, 명도로 지우면 불투명 마스크입니다.

블렌딩 모드

아래 있는 개체와 위에 있는 개체를 혼합하는 기능입니다. 배경 제거, 빛 표현, 색 보정에서 자주 씁니다.

Blend Modes
Multiply

곱하기

흰색에 가까울수록 투명하게 보입니다. 흰색 배경 제거, 종이 질감, 잉크 질감 합성에 많이 씁니다.

Screen

스크린

검은색에 가까울수록 투명하게 보입니다. 검은 배경 제거와 빛 표현에 적합합니다.

Color Dodge

컬러 닷지

검은색이 사라지고 색 대비가 강해집니다. 강한 광원이나 번쩍이는 효과를 만들 때 씁니다.

Overlay

오버레이

회색에 가까울수록 영향이 약합니다. 하이라이트, 그림자, 회색 기반 텍스처 합성에 유용합니다.

Color

색상

명도와 채도는 무시하고 색상만 남깁니다. 색 보정이나 특정 영역의 컬러 변경에 적합합니다.

이미지 관리

  • 1. 가져오기
    작업 화면을 열고, 작업 화면 안으로 이미지를 드래그해서 배치합니다.
  • 2. Embed
    연결된 이미지를 문서 안에 포함시킵니다. 외부 파일 누락 방지를 위해 중요합니다.
  • 3. Crop Image
    필요한 부분만 잘라서 정리합니다.
  • 4. Image Trace
    `Window > Image Trace`에서 실행합니다.
  • 5. 추천 옵션
    `Sketches Art`는 블랙/화이트 기반 작업에 유용하고, 흰색 부분을 투명하게 처리하는 데 도움이 됩니다.
  • 6. 마무리
    `Expand` 후 색상 패널 모드를 `RGB` 또는 `CMYK`로 확인합니다.

최종 암기 포인트

  • 클리핑 마스크는 액자 개체가 반드시 위에 있어야 합니다.
  • 클리핑 마스크의 액자는 패스이기만 하면 되고, 채우기와 선은 없어도 됩니다.
  • 여러 개의 액자를 쓰려면 그룹이 아니라 컴파운드 패스를 먼저 적용합니다.
  • 불투명 마스크는 검정, 회색, 흰색의 명도를 읽어서 투명도를 조절합니다.
  • Multiply는 흰색 제거, Screen은 검은색 제거에 자주 씁니다.
  • 이미지를 가져왔으면 Embed 여부를 꼭 확인합니다.
