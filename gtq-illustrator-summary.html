GTQ 일러스트 정리본

시험장에서 중요한 건 완벽함보다 속도와 점수 확보입니다. 이 자료는 수강생이 바로 훑고 실전에 적용할 수 있도록 시험 정보, 시간 배분, 초기 세팅, 주요 기능, 단축키를 한 장 흐름으로 정리한 참고자료입니다.

실전 핵심 한 줄

정확하게 그리려고 집착하면 시간에서 무너집니다. 먼저 색을 등록하고, 기능 적용과 문제 완성도를 우선 챙기고, 마지막 5분은 반드시 검수에 남겨두세요.

90 분 안에 끝내기
3 문제 구성
5 마지막 검수 시간
팁: 다 못 풀었더라도 기능은 반드시 적용해두기. 부분 점수가 남습니다.

시험 개요

시험의 큰 틀을 먼저 머리에 넣어두면 시간 배분과 풀이 순서 판단이 쉬워집니다.

중상

GTQ 일러스트는 기본 기능 숙련도와 빠른 처리 속도를 동시에 요구하는 편입니다.

90분

문제별 배분을 지키지 못하면 뒤 문제에서 무너질 가능성이 큽니다.

총 3문제

각 문제마다 색상 등록과 도형 구성, 기능 적용을 빠르게 처리해야 합니다.

검수 5분

마지막에는 레이어 순서, 색상 누락, 기능 적용 누락만 집중 확인합니다.

주의사항

점수에 직접 연결되는 실전 감각 위주로 정리했습니다. 시험장에서는 이 원칙만 지켜도 훨씬 안정적입니다.

정확함 집착 금지

정확하게 그리려고 오래 붙잡으면 떨어질 가능성이 커집니다. 빠르게 끝내고, 애매한 부분은 흐린 눈으로 넘어가는 판단이 필요합니다.

컬러 먼저 등록

문제 시작 후 바로 색을 등록해두세요. 등록한 색상은 해당 색 펜으로 체크하며 누락 없이 정리합니다.

시간 부족 시 풀이 순서

시간이 부족할 것 같으면 3 → 2 → 1 순서로 접근합니다. 뒤 문제의 배점과 난도를 먼저 챙기는 전략입니다.

부분 점수 확보

완성하지 못한 문제라도 기능은 적용해두세요. 결과물이 덜 끝나도 기능 사용 흔적이 있으면 점수를 건질 수 있습니다.

시험장 운영 원칙

가장 중요한 기준

  • 색상 등록과 레이어 순서를 초반에 안정화합니다.
  • 완성도를 조금 포기하더라도 전체 문제를 만져봅니다.
  • 도형 하나에 오래 매달리지 않습니다.
  • 기능 적용 여부는 눈에 보이는 점수 포인트라고 생각합니다.
  • 마지막 5분은 제작 시간이 아니라 오류 제거 시간입니다.

시간 배분

컬러 등록 시간과 제작 시간을 분리해서 생각하면 훨씬 덜 꼬입니다.

1번 문제

짧고 빠르게 처리

  • 컬러 등록: 5분 내
  • 문제 풀이: 15분
2번 문제

속도 유지하며 진행

  • 컬러 등록: 7분 내
  • 문제 풀이: 20분
3번 문제

배점 체감이 큰 구간

  • 컬러 등록: 7분 내
  • 문제 풀이: 35분
마지막 5분은 검수. 색상 누락, 레이어 위아래 순서, 기능 적용 여부를 끝까지 확인합니다.
1
색상 등록

문제 시작 직후 필요한 컬러를 먼저 등록하고 체크 표시까지 완료합니다.

2
도형 큰 틀부터

세부 디테일보다는 큰 형태와 배치를 먼저 잡아 전체 진행 속도를 올립니다.

3
기능 적용

패스파인더, 블렌드, 왜곡 등 채점 포인트가 되는 기능은 중간중간 바로 넣습니다.

4
최종 점검

미완성 문제도 그냥 두지 말고, 가능한 범위에서 기능이나 색상 적용 흔적을 남깁니다.

처음 세팅

시험 시작 후 바로 해야 하는 창 세팅과 환경설정입니다. 이 부분은 손에 익을 때까지 반복해야 합니다.

창 세팅

필수 패널 열기

  • Window → Control
  • Window → Toolbar → Advanced
환경설정

Ctrl + K 설정

  • Scale Corner 켜두고 작업하기
  • Scale Stroke & Effect 끄고 작업하기

주요 기능

시험에서 자주 등장하고, 빠른 제작에 직접 도움이 되는 기능만 모아 정리했습니다.

도형 결합

Pathfinder / Shape Builder

  • Pathfinder: 도형 합치기, 빼기, 나누기 기본.
  • Shape Builder 더하기: 드래그
  • Shape Builder 빼기: Alt 드래그 또는 클릭
  • Shape Builder 나누기: 클릭
변형

Rotate / Reflect

  • 회전과 반사는 중심축 지정이 중요합니다.
  • 중심축을 찍는 동시에 옵션창 띄우기: Alt + 클릭
빠른 드로잉

Knife / Blob Brush / Pencil

  • Knife: 면이나 도형 분할에 유용.
  • Blob Brush: 면으로 그려지는 브러시. 펜툴 대신 빠르게 그릴 때 사용.
  • Pencil: 닫힌 패스를 그릴 수 있어 빠른 작업에 유리.
왜곡

Envelope Distort

  • Ctrl + Alt + Shift + W: Make with Warp
  • Ctrl + Alt + C: Make with Top Object
  • 단축키가 기억 안 나면 Object → Envelope Distort로 접근
  • Make with Top Object는 왜곡시킬 틀이 반드시 레이어 순서상 위에 있어야 합니다.
반복/연결

Symbol / Blend

  • Symbol: 반복되는 요소를 관리할 때 유리
  • Ctrl + Alt + B: Blend 실행
  • W 후 Enter: Blend 옵션 열기
패턴

패턴 크기만 조절하기

  • Scale Tool → Enter
  • Transform Pattern만 체크하고 조절
  • 도형 크기는 유지하고 패턴만 확대/축소할 때 사용

반복 사용 빈도가 높은 단축키만 빠르게 눈에 들어오도록 묶었습니다.

핵심 요약: GTQ 일러스트는 예쁘게 그리는 시험이 아니라, 제한 시간 안에 기능을 정확히 적용해 점수를 회수하는 시험입니다. 빠른 판단, 선등록한 컬러, 기능 적용 흔적, 마지막 검수 5분을 끝까지 지키세요.
