1. 왜곡 도구 핵심 정리

모양을 바꾸는 목적이 서로 다르기 때문에, 어떤 도구를 언제 쓰는지 구분하는 것이 중요합니다.

도구 구분

Free Transform

Perspective Distort

기본 도형이나 오브젝트를 원근감 있게 밀어 사다리꼴 형태로 바꾸고 싶을 때 사용합니다.

시험·수업 포인트
Perspective Distort는 "사다리꼴"을 떠올리면 됩니다.

Puppet Warp

핀 고정

오브젝트 위에 핀을 꽂고 부분적으로 당기듯 변형합니다. 팔다리, 리본, 캐릭터 포즈에 특히 유용합니다.

  • 고정할 곳은 핀으로 잡아 둡니다.
  • 움직일 곳만 선택적으로 휘게 만들 수 있습니다.

Warp Tool

밀고 당기기

브러시처럼 문질러 오브젝트를 밀어내거나 휘게 만드는 도구입니다. 자연스럽고 자유로운 왜곡에 적합합니다.

  • 정확한 수치형 왜곡보다 감각적인 수정에 강합니다.
  • 실루엣 정리나 유기적 형태 수정에 자주 씁니다.

Object > Intertwine

얽힘

겹쳐진 오브젝트의 앞뒤 순서를 일부 구간만 교차시켜 진짜 엮인 것처럼 보이게 만듭니다.

핵심 이미지
"겹친다"가 아니라 "얽힌다"는 느낌으로 기억하세요.

2. 텍스트 작성 방식과 편집

글자는 입력 방식부터 다릅니다. 클릭해서 쓰는지, 드래그해서 쓰는지에 따라 성격이 달라집니다.

텍스트 기본

Point Text

클릭해서 작성합니다. 제목, 짧은 문구, 자유로운 배치에 적합합니다.

  • 크기를 자유롭게 조절하기 쉽습니다.
  • 짧은 텍스트나 로고 문구 작업에 자주 사용합니다.
한 줄 제목이나 짧은 문장에 적합

Area Text

드래그해서 작성합니다. 정해진 박스 안에 문단을 넣을 때 사용합니다.

  • 문단 흐름과 줄바꿈을 관리하기 좋습니다.
  • 전단지, 리플렛, 설명문처럼 긴 텍스트에 적합합니다.
정해진 영역 안에서 줄이 자동으로 바뀌며 문단처럼 정리됩니다.

텍스트 전환 메뉴

1
Type > Convert to Point Text
영역형 텍스트를 포인트 텍스트로 바꿉니다.
2
Type > Convert to Area Text
포인트 텍스트를 영역형 텍스트로 바꿉니다.
3
Type > Change Case
영문 대문자·소문자를 바꿉니다.

행간 기준

가독성이 좋은 행간은 보통 글씨 크기의 1.4배~1.8배를 기준으로 잡습니다.

예시
글자 크기 10pt라면 행간은 대략 14pt~18pt 범위에서 먼저 맞춰 보고, 문단 길이와 분위기에 따라 세부 조정합니다.

행간이 너무 좁으면 답답하고, 너무 넓으면 문장이 끊겨 보여 읽기 힘들어집니다.

3. 아웃라인과 작업 흐름

글자는 수정 가능한 상태로 작업하다가, 최종 단계에서 윤곽선으로 바꾸는 흐름을 익혀 두면 좋습니다.

실무 흐름

Create Outline

Ctrl Shift O

Create Outline은 글자를 윤곽선 오브젝트로 바꾸는 기능입니다. 수업에서 흔히 "글자를 깬다"라고 표현합니다.

주의
아웃라인을 만들면 일반 텍스트처럼 다시 입력 내용을 수정하기 어렵습니다. 오탈자 확인과 문장 수정이 끝난 뒤 마지막 단계에서 사용하는 것이 안전합니다.

작업 순서 추천

  1. Point Text 또는 Area Text로 먼저 입력합니다.
  2. 행간, 크기, 대소문자, 정렬을 수정합니다.
  3. 필요하면 왜곡이나 배치 작업을 진행합니다.
  4. 최종본에서만 Create Outline으로 넘깁니다.

기억해야 할 한 줄 정리

A
Perspective Distort는 사다리꼴 원근 왜곡.
B
Puppet Warp는 핀을 꽂아 부분 변형.
C
Warp Tool은 문질러 자유롭게 형태 수정.
D
Intertwine는 앞뒤가 일부 교차하며 얽힌 효과.
E
Point Text는 클릭, Area Text는 드래그.
F
Create Outline = Ctrl + Shift + O = 글자를 깬다.

5. 복습문제

읽고 끝내지 말고 직접 선택하고 입력해 보세요. 객관식과 매칭 문제는 채점되고, 서술형은 예시 답안을 볼 수 있습니다.

실전 확인
점수: 아직 채점 전

1. 사각형을 원근감 있는 사다리꼴처럼 보이게 만들 때 가장 직접적으로 연결되는 기능은 무엇인가요?

2. 다음 설명에 맞는 텍스트 종류를 고르세요.

3. 글자를 윤곽선 오브젝트로 바꾸는 단축키를 입력하세요.

4. 다음 중 설명이 알맞은 것을 고르세요.

5. 왜 글자는 수정이 끝난 뒤 마지막 단계에서 아웃라인을 만드는 것이 좋은지 두 문장 안으로 적어 보세요.

인쇄해서 사용할 경우 서술형은 손글씨로 작성해도 되고, 화면으로 사용할 경우 바로 입력하면 됩니다.
